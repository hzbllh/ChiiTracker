# 💰 Money Tracker

A simple, beautiful, and private **Money Tracker** web app built with vanilla HTML, CSS, and JavaScript.

- ✅ Dark / Light mode
- ✅ Income & Expense tracking
- ✅ Categories with colors
- ✅ Pie chart (expenses by category)
- ✅ Bar chart (monthly trend)
- ✅ Filter by month
- ✅ Data saved in browser (`localStorage`) — 100% private
- ✅ Responsive (mobile & desktop)
- ✅ Ready for GitHub Pages

**No backend. No account. No tracking.**
